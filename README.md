# Jacob Pakkiyaretnam — Portfolio

**Live site: [jacob18299.github.io](https://jacob18299.github.io)**

Personal portfolio of an AI engineering student in Canberra, Australia.
Built as a single self-contained `index.html` — no build step, no
dependencies, hosted free on GitHub Pages.

## What's inside

Three shipped projects, three different architectures, all running on
local AI models on an 8 GB laptop with no cloud APIs:

- **[local-rag](https://github.com/Jacob18299/local-rag)** — CLI tool.
  Ask questions about a folder of documents, get answers with citations.
- **[meeting-summarizer](https://github.com/Jacob18299/meeting-summarizer)** —
  Flask web app. Paste a transcript, get a summary, decisions and action items.
- **[company-enrichment-api](https://github.com/Jacob18299/company-enrichment-api)** —
  Headless FastAPI service. Company name in, typed structured facts out.

Plus my AI engineering work placement at Bluerydge, Hugging Face course
certificates, and what building these projects taught me.

## The site itself

- Hand-built HTML/CSS/JS, inlined into one file (fonts, images and all)
- Interactive touches: hover stickers, certificate lightbox, magnetic button,
  custom cursor
- Responsive, respects `prefers-reduced-motion`
